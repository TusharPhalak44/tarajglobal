# Taraj Global - Enterprise Corporate Website

A production-ready enterprise-grade corporate website built with React 19, Node.js, Express, and MySQL.

## Project Structure

```
tarajglobal-clone/
├── client/          # React 19 Frontend
├── server/          # Node.js/Express Backend & MySQL Database Schema
├── docs/            # Documentation
├── README.md
├── package.json
└── .gitignore
```

## Tech Stack

- React 19

- React Router DOM
- Tailwind CSS
- Axios

### Backend
- Node.js

- Helmet
- CORS
- dotenv
- Multer
- Nodemailer
- Express Validator

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- MySQL (XAMPP)
- npm or yarn

### Installation

1. Clone the repository
2. Install root dependencies:
   ```bash
   npm install
   ```

3. Install client dependencies:
   ```bash
   cd client
   npm install
   ```

4. Install server dependencies:
   ```bash
   cd server
   npm install
   ```

### Configuration

1. Set up MySQL database using the schema in `server/database/schema/tarajglobal.sql`
2. Configure environment variables (see `.env.example` files)
3. Start the development servers

### Running the Project

**Frontend (Client):**
```bash
cd client
npm run dev
```

**Backend (Server):**
```bash
cd server
npm run dev
```
